## 📋 Overview
This project is a high-fidelity, conversion-focused landing page for **RecruiterAI**, an automated recruiting platform. This application demonstrates a complete product cycle: from understanding the problem to designing the solution and shipping production-ready code.

The landing page effectively communicates how AI solves hiring pain points through automated screening, interviewing, and re-engagement workflows.

## ✨ What I Built (Key Features)

### 1. 💎 Polished Hero Section
* A central value proposition surrounded by "floating" conversation bubbles that represent real user pain points.

### 2. mj Automated Workflow Visualizer
* Visualizing the "Black Box" of AI recruiting. A responsive Layout displaying distinct workflows:
    * **Screening:** Application → AI Resume Screen → Auto-Schedule.
    * **Interview:** Video Interview → AI Scoring → Hiring Decision.
    * **Nurture:** Rejection → Talent Pool → Auto Re-engagement.

### 3. 📊 Impact Metrics
* Social proof through data. A clean data visualization section using vertical bar charts and bold typography.

### 4. ♾️ Infinite Logo Slider
* "Post Once, Reach Everywhere". A seamless, auto-scrolling integration. Logos feature a professional grayscale-to-color hover effect.

### 5. 🌙 Dark Mode Support
* **Value Add:** Going beyond the requirements, I implemented a fully integrated dark theme with a manual toggle, utilizing the official RecruiterAI dark palette.

### 6. 💬 Trusted by Founders (Testimonials)
* A responsive grid layout featuring realistic personas (Founders & Hiring Managers). Each card is designed with a clean, trustworthy aesthetic containing:
    * **User Profile:** Avatar, Name, and Title.
    * **Impact Quotes:** Specific mentions of time reduction (e.g., "6 weeks to 10 days") to reinforce the product's value proposition.

### 7. ❓ Interactive FAQ Section
* Addressing user objections upfront to reduce friction FAQ
    * **Clean UI:** Questions are listed cleanly; answers expand on click to save vertical screen space.

## ⚡ Getting Started
### Prerequisites
* Node.js (v14 or higher)

* npm or yarn

### Installation
1. Clone the repository

~~~Bash
git clone https://github.com/PoshikaM/RecruiterAI.git
cd recruiter-ai
~~~

2. Install dependencies

~~~Bash
npm install
~~~

3. Start the development server

~~~Bash
npm run dev
~~~

Open http://localhost:5173 to view it in the browser.
